## 四、light-c 便携版数据自包含（本轮补齐 ✅）

**v2.16.15 portable 实测**：`data_dir_mode=relative`，config/data/snapshots/logs 全在 exe 旁。
**我方此前**：便携 exe 仍写 %APPDATA%\com.cdisksavior.app（不绿色）。
**本轮修复**：
- `appdata::portable_mode()`：exe 同目录有 manifest 标记，或 exe 名含 "portable" → 判便携
- `data_dir()` 解析顺序：缓存 → **便携**（exe 旁 /data） → 自定义 → 默认
- 增长快照 / 残留白名单 / 迁移历史 / 迁移配置 四处全部跟随 `appdata::data_dir()` 解析
- **安装版数据位置不变**（兼容老数据）
