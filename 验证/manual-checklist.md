# CDisk Savior 实机手动验证清单（D 级 · GUI/交互部分）

> 自动化脚本 `verify-machine.ps1` 覆盖系统层检查；本清单覆盖只能在应用界面内验证的场景。
> 每项记录：实际结果 ✅/❌ + 备注。执行顺序即检查顺序。

## 0. 前置

- [ ] 0.1 以管理员身份安装 `CDSavior-Setup.exe`，安装过程无报错
- [ ] 0.2 启动应用，主界面正常渲染（非白屏），左侧导航 5 个页面可切换

## 1. MFT 双引擎快路径（light-c 引擎，需管理员权限）

- [ ] 1.1 磁盘透视 → 大文件 tab → 扫描 C:\：秒级出结果（<10s），Top 列表非空、大小降序
- [ ] 1.2 磁盘透视 → 热点 tab：秒级出结果，AppData 三根下目录大小/文件数合理，>5GB 大目录有 3 个子目录下钻
- [ ] 1.3 增长 tab → 创建基线：秒级完成（对比 jwalk 路径的分钟级）
- [ ] 1.4 增长 tab → 分析：无基线时自动建基线并提示；有基线后文件明细只列基线后修改/新增文件，分页正常（500/页）
- [ ] 1.5 扫描期间进度计数实时增长；取消按钮可中断（结果带 cancelled 标记或按钮恢复）

## 2. MFT 服务（ntfs-reader 引擎，C1）

- [ ] 2.1 设置页「MFT 扫描服务」显示已注册；未注册时「一键修复」按钮可用且修复后变已注册
- [ ] 2.2 磁盘透视 → TreeMap tab → 扫描 C:\：秒级出结果，treemap 块面积与大小成正比
- [ ] 2.3 TreeMap 点击目录块下钻、面包屑返回、悬停显示路径+大小+占比

## 3. 空间腾挪（迁移，§8 实证场景）

- [ ] 3.1 迁移一个测试目录（如 C:\Users\<你>\Documents\TestMove，内含若干文件）到 D 盘：
  完成后原位置变为 junction（资源管理器图标带快捷方式角标），D 盘目标含全部文件，mtime 保留
- [ ] 3.2 含空格与 & 的路径（如 `C:\Test Dir&A`）迁移成功（V16 用例）
- [ ] 3.3 目标盘剩余空间不足时拒绝并提示「需要 X GB，实际剩余 Y GB」（V10 预检）
- [ ] 3.4 迁移中途强制结束应用进程：重启应用后历史页显示该迁移为可恢复/可清理状态（无半成品）
- [ ] 3.5 恢复迁移：junction 删除、目录搬回原位、文件数与大小与迁移前一致（V2 前置）
- [ ] 3.6 非法 target_root 拒绝：迁移目标选 C:\Windows 时给出拒绝原因
- [ ] 3.7 双实例：已开应用时再启动第二个实例，第二个直接退出（脚本已自动验证，此条复核 UI 无异常弹窗）

## 4. V2 孤儿扫描（junction 防误删）

- [ ] 4.1 完成 3.1 迁移后，到设置/工具里卸载该测试软件（或手动删除其卸载注册项），
  运行「卸载残留」孤儿扫描：junction 目录**不得**出现在待删列表中

## 5. 长路径（R9/V20，需系统开启 LongPathsEnabled 组策略/注册表）

- [ ] 5.1 在 D 盘构造 >260 字符的深路径（如 30 层 node_modules 式目录），迁移或删除操作不报错
  （系统未开 LongPathsEnabled 时此条预期失败，属系统限制，记为 N/A 并注明）

## 6. 软件体检（Q4 bloatware）

- [ ] 6.1 清理页底部「软件体检」区块加载已安装软件列表，图标显示（exe 图标抠取）
- [ ] 6.2 后台常驻检测：运行中的软件标注内存占用（sysinfo）
- [ ] 6.3 标准卸载可发起；「强力模式」生成计划（服务/任务/目录/注册表清单预览）
- [ ] 6.4 卸载历史记录展示

## 7. 深度清理与删除（P2 删除系）

- [ ] 7.1 深度扫描 18 类出结果，进度按分类推进，可取消
- [ ] 7.2 选若干低风险类删除（回收站模式）：回收站可见被删项；再删一类选永久删除
- [ ] 7.3 集合外路径删除被拒绝（Skipped，V28）

## 8. 社交缓存与其他页面

- [ ] 8.1 社交缓存扫描出微信/QQ 缓存项，删除后空间释放
- [ ] 8.2 设置页：检查更新灰置不可点；数据目录可迁移；存储诊断六项可写实测通过
- [ ] 8.3 启动项管理：禁用/启用生效；对一个不存在的启动项 id 操作给出「已不存在」错误（V27）

## 9. 卸载

- [ ] 9.1 存在未恢复迁移时卸载：弹出「检测到未恢复迁移记录」警告（Q8 钩子）
- [ ] 9.2 卸载完成后 CDiskSaviorSvc 服务已删除、安装目录清空
