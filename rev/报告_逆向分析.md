## 3. 运行时架构

```
C盘管家.exe  (asInvoker, WebView2 + React UI)
│
├─ 普通扫描 ──► 用户态遍历（jwalk + rayon，多线程目录遍历）
│
├─ 深度扫描 ──► 命名管道 \\.\pipe\disk-butler-scan  ──►  disk-butler-svc.exe
│                  （JSON 请求/响应，流式 progress）        （LocalSystem 服务
│                                                             DiskButlerScanSvc）
│                                                             └─ 直读卷 \\.\C: 的
│                                                                $MFT 解析 NTFS
│
└─ 系统级清理 ──► UAC 提权子进程
     ├─ cmd.exe  /d /c  Dism /Online /Cleanup-Image /StartComponentCleanup   (WinSxS 组件清理)
     ├─ powershell.exe -NoProfile -EncodedCommand <Base64>                  (系统临时文件等)
     └─ disk-butler-svc.exe install  -Verb RunAs -WindowStyle Hidden        (安装扫描服务)
        之后 sc.exe sdset DiskButlerScanSvc <SDDL>
```

**实测证据：**

- 管道与服务名：`DiskButlerScanSvc`、`\\.\pipe\disk-butler-scan` @ `0x7d5039`(主) / `0x852e2`(服务)
- 服务安装：`Start-Process -FilePath '<path>' -ArgumentList 'install' -Verb RunAs -Wait -WindowStyle Hidden` @ `0x7d4e32`
- 服务 CLI：` install / uninstall / run-console ` @ `0x85381`
- 服务 DACL 下发：`sc.exe` + `sdset` @ `0x85440`
- DISM：`Start-Process -Verb RunAs -Wait -PassThru -FilePath cmd.exe -ArgumentList '/d','/c','Dism /Online /Cleanup-Image /StartComponentCleanup > "<log>" 2>&1'; exit $p.ExitCode` @ `0x7ce5df`
- Base64 PowerShell：`powershell.exe -ArgumentList '-NoProfile','-EncodedCommand',<b64>` @ `0x7cec46`
- 提权失败文案：`修复未完成（可能取消了管理员授权），请重试`、`启动提权进程失败：`、`需要管理员权限：请右键以管理员身份运行本程序后再修改系统级启动项。`

### 服务安全描述符（**实测**，`0x8544b`）

```
D:(A;;CCLCSWRPWPDTLOCRRC;;;SY)
  (A;;CCDCLCSWRPWPDTLOCRSDRCWDWO;;;BA)
  (A;;CCLCSWLOCRRC;;;IU)

## 4. 前端资源还原（本次分析的技术核心）

Tauri v2 将前端构建产物以 **Brotli 压缩**内嵌在 `.rdata`。容器格式（**实测**，逆向得到）：

```
资源表位于文件偏移 0x7C9320，每条 32 字节：
  [u64 path_ptr][u64 path_len][u64 data_ptr][u64 data_len]   // VA = ImageBase(0x140000000) + RVA
数据区紧跟路径字符串，为裸 Brotli 流（无额外头）
```

| 逻辑路径 | 压缩 | 还原 | SHA-256（还原后） |
| --- | --- | --- | --- |
| `/assets/index-B1F9_IYX.css` | 6,467 B | **35,242 B** | `91b49158fba56011...` |
| `/index.html` | 236 B | **458 B** | `f2c64e8b589e3b4d...` |
| `/tauri.svg` | 1,289 B | 2,605 B | `3f32698a9cb64f4d...` |
| `/vite.svg` | 712 B | 1,497 B | `4a748afd443918bb...` |
| `/assets/index-D5S41rDQ.js` | 118,609 B | **425,252 B** | `8516956450ff27a4...` |

> 工程提示：该容器**没有**魔数、没有 `0x1b` 之类的长度前缀字节（初看像前缀的 `1b` 其实是压缩流首字节）。
> 定位正确起点的方法不是猜偏移，而是先找到 32 字节资源表、按 `data_ptr` 精确定位。

**前端技术栈（实测，来自还原后的 JS）：** Vite 构建 + **React 19**（`jsx`/`useState` 自动 JSX runtime）+ **Framer Motion**（`layout`/`animate`/`exit`）+ **Tailwind CSS**（`text-[var(--color-text-secondary)]` 风格）+ `d3-hierarchy`（TreeMap）。

> 修正（源码核验后）：初判为 React 18 有误，`package.json` 与 `package-lock.json` 实测为 **react 19.2.8 / tailwindcss 4.3.3 / vite 7.3.6 / typescript 5.8.3**。
`index.html`：`<html lang="zh-CN">`、`<title>C盘管家</title>`、挂载点 `<div id="root">`。

## 6. 数据模型 / Schema（实测）

**扫描树节点 `TreeNode`（10 字段）**
`name, path, size, isDir, hasChildren, category, friendlyName, description, safety, children`
- `category`: `cache` / `software` / `personal`(个人文件) / `systemFile`(系统文件) / `other`(未识别)
- `safety`: `safe`(可安全清理) / `caution`(谨慎操作) / `keep`(请勿删除)
- 合并哨兵：路径以 `::__others__` 结尾 = UI 折叠的小项目组（前端显示为「（合并的小项目）」）

**扫描进度（流式，来自 svc）**
`position, size, filesScanned, bytesScanned, percent, phase`

**命名管道帧（`src\svc.rs`）**
请求：`{ cmd, root, ... }` ；响应：`{ type: "progress" | "done" | "tree" | "error" | "message", ... }`
（`0x868c0` 连续字符串 `disk-butler-scan` `cmd` `src\svc.rs` `root` `type` `done` `tree` `error` `message`）

**持久化文件**
- 扫描缓存：`scan-cache-<...>.json` = `ScanCache { scannedAt, root, tree }`
- 清理统计：`cleanup-stats.json` = `{ totalFreed, totalRuns, lastAt }`
- 前端主题：`localStorage["diskbutler-theme"]`
- DISM 日志：`diskbutler-dism-*.log`
- 规则采集报告：`diskbutler-rule-report-*.json` / `.md`

**WMI / 系统查询**：`Get-CimInstance Win32_PageFileUsage`（页面文件）；`K32GetPerformanceInfo` / `GlobalMemoryStatusEx`（内存）；`GetDiskFreeSpaceExW` / `GetLogicalDrives` / `GetDriveTypeW`（卷）。
**系统识别**：`SOFTWARE\Microsoft\Windows NT\CurrentVersion` → `CurrentBuildNumber` 判 `Windows 10` / `Windows 11`。

## 8. 功能与规则知识库

界面为四个页签（实测，JS 常量数组）：

| 页签 id | 名称 | 副标题 |

### 8.3 AppData 孤儿目录判定（原文收录标准，实测）

```
# 入库标准（宁漏报不误报）：
#  1. 目录名 = 单一软件专属，无跨软件/厂商复用（Google/Tencent/Kingsoft 等厂商级目录永不入库）；
#  2. 软件为安装器分发（绿色/便携常客如 Snipaste/Everything 不入库——无注册表条目会被误判孤儿）；

#     纯本地用户资产（剪映草稿、Postman workspace、聊天记录类）仍然绝不入库。
# 别名用于"在装判定"：任一别名命中任何在装软件的名称/发行商/安装路径 → 视为有主，绝不判孤儿。

条目格式：`目录名|软件人话名|在装匹配别名(逗号分隔)|警示语(可选)`。

## 9. 安全评估

### 9.1 正面（设计上克制）

| # | 结论 | 证据 |
| --- | --- | --- |
| 1 | **完全离线运行**，无遥测、无自动上报 | 无 `ws2_32/winhttp/TcpStream`；导入表无网络 DLL |
| 2 | 默认 `asInvoker`，不强制提权 | 清单无 `requestedExecutionLevel` |
| 3 | 提权仅按需、且必须用户点 UAC | `-Verb RunAs` + 文案「弹出系统授权窗口（UAC）」 |
| 4 | **提权组件只读不写**：服务端无任何删除 API | 服务导入表仅 `kernel32/advapi32/ntdll/oleaut32`，无 `shell32`、无 `SHFileOperation`、无 `DeleteFileW` 使用证据；实际删除在用户态主程序 |
| 5 | CSP 严格，禁远程脚本/远程连接 | `script-src 'self'`、`connect-src ipc: http://ipc.localhost` |
| 6 | Tauri v2 ACL 白名单生效 | 存在 `allow-*`/`deny-*` 权限名；`Command not allowed by ACL` |
| 7 | 破坏性操作有二次确认与文案警示 | 「将永久删除勾选的 N 个文件夹（不进回收站）。确定里面没有要留的东西了吗？」 |
| 8 | DISM 删组件前有白名单闸门 | 字符串「不在白名单中，已拒绝」 |
| 9 | 启动项禁用可逆，且受保护项不被改 | 建议库含 `keep` 类；`ctfmon/securityhealth` 等标记保留 |

### 9.2 风险与不足

| 级别 | 问题 | 说明 |
| --- | --- | --- |
| 中 | **两个二进制均无 Authenticode 签名** | 会触发 SmartScreen 警告；且无法防篡改/仿冒，第三方可打出同名同版本号的木马 |
| 中 | **存在不可逆永久删除路径** | 「高级 · 系统深度清理」走 DISM `StartComponentCleanup`（清理 WinSxS 旧备份，系统升级后无法回滚）与 PowerShell 直删；**不进回收站** |
| ~~中~~ **已排除** | ~~命名管道访问控制未能静态确认~~ → **源码核验后确认实现优于假设，风险排除** | 管道创建时显式设置了安全描述符 `D:(A;;GA;;;SY)(A;;GA;;;BA)(A;;GRGW;;;AU)`，并带 `PIPE_REJECT_REMOTE_CLIENTS`（拒远程连接）、单实例、请求长度上限 4096 字节、指令白名单（仅接受 `"scan"`）。**残留低危项**：管道对已认证用户授予读写，本机其他非特权用户可请求一次全盘 MFT 扫描并取得完整文件树（含全盘文件名）—— 单用户家用机可忽略，多用户/共享机器属低危信息泄露 |
| 低 | 服务 DACL 授予 `IU/SU/AU` `SERVICE_START` | 非管理员可启动服务（但不能停/改），属常规做法但扩大了触发面 |
| 低 | 提权子进程使用 `-EncodedCommand` Base64 调用 PowerShell | 自身行为正当（避免引号转义），但与攻击者常用手法同形，易被 EDR 关注/误报 |
| 低 | 路径拼接与白名单判定为主观规则 | 清理目标由"知识库"决定，规则误判即可能误删用户数据；项目以"警示语 + 人工确认"缓解 |
| 信息 | 构建路径 `C:\Users\l3268\` 泄漏进二进制 | 无实质危害 |

### 9.3 权限与危险面小结

- 主程序：普通用户权限即可完成扫描、回收站删除、启动项（HKCU）修改。
- 提权路径共 3 条：① DISM 组件清理；② PowerShell 系统临时文件清理；③ 安装/修复扫描服务。三者均由用户在 UI 显式触发。
- 服务：`LocalSystem`，能力 = 读原始卷 + 解析 MFT + 管道收发 JSON。**无删除、无写入系统目录的证据。**
